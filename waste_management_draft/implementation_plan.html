Master Implementation Plan

WasteWise: Comprehensive Smart Waste System

This plan combines the core urban waste management logic with the new user-centric penalty and tracking system. The goal is a modular, zero-dependency Python application that simulates both Individual Responsibility (disposal) and City-wide Efficiency (collection).

IMPORTANT: Integration Flow When a user adds waste, the system will immediately calculate penalties (User Responsibility) AND update the global bin state (City Infrastructure). Once a bin is full, the system will trigger the priority/allocation logic (Operational Efficiency).
NOTE: Data Generation I will generate 20 category-specific CSV files with varied compositions to ensure the random-selection requirement provides meaningful test data.

Proposed Changes

Phase 1: User Responsibility & Input

[NEW] input_handler.py

  • InputProcessor: Handles immediate logic for every disposal event.
  • Login: Manages current user_id.
  • CSV Selector: Randomly chooses one of 5 CSVs for the selected category.
  • Contamination Calc: quantity * invalid_sum based on allowed types.
  • Penalty Calc: contamination * severity * base_rate.

[NEW] logger.py

  • CSV Logging: Appends every event with Input ID, User ID, Bin ID, Category, Qty, Contamination, and Penalty to logs/disposal_events.csv.

[NEW] data/composition/

  • 20 randomized CSV files stored in category-specific subdirectories.
